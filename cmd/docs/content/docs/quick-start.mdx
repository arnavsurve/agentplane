# Quick Start

## 1) Create and get a key

| Step | Action |
|------|--------|
| 1 | Sign in → Create Agent |
| 2 | Agent → API tab → Generate New Key |
| 3 | Copy the key (shown once) |

## 2) Call the API

Run one of these:

### cURL
```bash
export GLYFS_AGENT_ID="REPLACE_ME"
export GLYFS_API_KEY="apk_REPLACE_ME"

curl -sS -X POST "https://glyfs.dev/api/agents/$GLYFS_AGENT_ID/invoke" \
  -H "Authorization: Bearer $GLYFS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message": "Say hi in one short sentence"}' | jq
```

### JavaScript (Node)
```js
const AGENT = process.env.GLYFS_AGENT_ID;
const KEY = process.env.GLYFS_API_KEY;

const res = await fetch(`https://glyfs.dev/api/agents/${AGENT}/invoke`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ message: 'Say hi in one short sentence' }),
});
console.log(await res.json());
```

### Python
```python
import os, requests
agent = os.environ['GLYFS_AGENT_ID']
key = os.environ['GLYFS_API_KEY']

r = requests.post(
  f"https://glyfs.dev/api/agents/{agent}/invoke",
  headers={
    'Authorization': f'Bearer {key}',
    'Content-Type': 'application/json'
  },
  json={ 'message': 'Say hi in one short sentence' }
)
print(r.json())
```

Expected shape:
```json
{
  "response": "Hello! 👋",
  "usage": { "prompt_tokens": 7, "completion_tokens": 3, "total_tokens": 10 }
}
```

## 3) Stream it (optional)

### cURL (SSE)
```bash
curl -N "https://glyfs.dev/api/agents/$GLYFS_AGENT_ID/invoke/stream" \
  -H "Authorization: Bearer $GLYFS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message": "Count to 3"}'
```

You’ll see events like:
```
data: {"type":"metadata","data":{"agent_id":"..."}}
data: {"type":"token","content":"One"}
data: {"type":"token","content":" … "}
data: {"type":"token","content":"Two"}
data: {"type":"done","data":{"response":"One … Two … Three."}}
```
